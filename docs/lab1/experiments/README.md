# LAB1 Experiments & Outputs Index

All experiment outputs, model checkpoints, plots, and Optuna databases generated during LAB1 are preserved here:

* `practice_1/`: Primary evaluation outputs, confusion matrices, and model checkpoints.
* `error_analysis/CNN/`: CNN architectural variants, Optuna study database (`optuna_study.db`), loss variants (focal loss, weighted loss, label smoothing), and training loss histories.
* `error_analysis/MLP/`: MLP depth/width sweeps, diagnostics, and Optuna HPO trial records (`all_trials.csv`, `optuna_study.db`, Plotly interactive HTML plots).
