## Rules

1. **Only use approved tools** listed above
2. **Log every interaction** in `AI_USAGE_LOG.md`
3. **Never share** passwords, API keys, `.env` files, or personal data with AI tools
4. **Review all output** before using — AI can hallucinate APIs, libraries, and logic

## Request a New Tool

To add a new AI tool, submit to the Project Lead:
- Tool name and version
- License/pricing
- Intended use cases
- Data privacy policy
- Risk assessment (Low/Medium/High)
