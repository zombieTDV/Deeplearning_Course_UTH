# Docs/ai_outputs

## Purpose
This directory stores unedited, raw AI-generated outputs created during development to maintain academic transparency, auditability, and traceability.

## Structure & Contents
- `requirements/`: Raw AI output for user stories and system requirements.
- `design/`: Raw AI generation logs for architecture diagrams and database schemas.
- `code/`: Raw AI-generated code snippets and implementation drafts.
- `testing/`: Raw AI output for test plans and test data generation.

## Naming Convention
- Format: `YYYY-MM-DD-description.md`
- Example: `2026-07-26-auth-api-generation.md`

## Responsible Person
- All team members
