# Docs/DECISION_RECORDS

## Purpose
This directory stores Architecture Decision Records (ADRs) documenting why technical decisions were made, key trade-offs, and context surrounding architectural and AI-assisted design choices.

## Contents
- Sequential markdown documents detailing technical choices, rationale, consequences, and alternative options considered.

## Naming Convention
- Format: `ADR-NNN-short-description.md`
- Examples: `ADR-001-database-choice.md`, `ADR-002-state-management.md`

## Responsible Person
- Tech Lead, Project Lead / AI Governance Officer
