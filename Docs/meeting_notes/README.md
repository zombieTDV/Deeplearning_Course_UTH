# Docs/meeting_notes

## Purpose
This directory stores official documentation and action items from team meetings, sprint planning sessions, daily standups, and retrospectives.

## Contents
- Meeting minutes, standup logs, sprint planning summaries, and retrospective action items.

## Naming Convention
- Format: `YYYY-MM-DD-meeting-type.md`
- Examples: `2026-07-26-sprint-planning.md`, `2026-07-26-retrospective.md`

## Responsible Person
- Project Lead / AI Governance Officer, Documentation Manager / QA Tester
