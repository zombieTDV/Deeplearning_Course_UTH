# Docs/reviews

## Purpose
This directory maintains code review checklists, peer review records, and audit documentation for validating AI-generated artifacts.

## Structure & Contents
- `code_reviews/`: Completed peer code review checklists and review notes.
- `ai_reviews/`: Audit records evaluating accuracy, security, and quality of AI outputs.

## Naming Convention
- Code reviews: `CR-YYYY-MM-DD-NNN.md` (e.g., `CR-2026-07-26-001.md`)
- AI reviews: `AIR-YYYY-MM-DD-NNN.md` (e.g., `AIR-2026-07-26-001.md`)

## Responsible Person
- All Developers (as reviewers)
