# Docs/testing

## Purpose
This directory contains test management documentation, including overall test strategies, detailed test cases, and test execution reports.

## Structure & Contents
- `test_cases/`: Specifications and documentation for individual test cases.
- `test_reports/`: Summary reports recording execution results and defect tracking.

## Naming Convention
- Test cases: `TC-NNN-short-description.md` (e.g., `TC-001-login-validation.md`)
- Test reports: `TR-YYYY-MM-DD-description.md` (e.g., `TR-2026-07-26-sprint-1.md`)

## Responsible Person
- QA Testers
